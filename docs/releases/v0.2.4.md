# mtty v0.2.4

[简体中文](v0.2.4.zh-CN.md)

## Reliable Unicode terminal titles

Chinese and emoji titles no longer stop at UTF-8 continuation bytes that overlap
C1 control values. Title updates survive arbitrary PTY chunk boundaries, including
split terminators. (#139)

Interrupted OSC/DCS/APC strings now recover on CAN, SUB, or a new escape sequence,
so the next title is processed independently. Dropping an oversized sequence also
clears its UTF-8 state. The host replay-boundary scanner distinguishes standalone
C1 ST from UTF-8 bytes, and the VT parser receives the equivalent terminator so
text following a title remains visible. (#145)

The hosted-title snapshot and restart behavior from v0.2.3 is retained.

## Command-key tab targets on macOS

Hold Command in a focused window to reveal targets 1–9 in tab icon slots, matching
Command+1 through Command+9. Releasing Command or losing focus restores the icons.
The horizontal tab bar and session sidebar keep their titles, widths, and hitboxes;
tabs beyond nine retain their icons. (#141)

## Regression coverage and packages

Parser and graphics fixtures use byte pipes instead of unnecessary shells and
PTYs, avoiding macOS PTY exhaustion during parallel tests. Explicit real-shell and
hosted snapshot/reattach integration tests remain in place. (#143)

Regression coverage includes all chunk sizes, Unicode titles, three terminators,
interrupted-string recovery, following screen text, and Command/focus transitions.
Workspace tests, Clippy, rendering and Release performance gates validate the
combined changes. The release pipeline checks platform package contents, update
manifest checksums, and detached signatures before publication.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and deb;
Windows x86-64 ZIP and MSI.
