# mtty v0.2.5

[简体中文](v0.2.5.zh-CN.md)

## Scrollable tabs and unobstructed titlebar controls

The tab strip stays within a bounded horizontal viewport when many or long titles
are open. Browse with horizontal trackpad gestures, a regular mouse wheel, or
Shift+wheel. Manual scrolling stays where you leave it; changing the selection
reveals the active tab without turning chip-reorder drags into viewport drags.
(#148)

The top-right panel, font and window controls are laid out first. Their actual
width is reserved, and tab/title painting and hit-testing are clipped to the
remaining area. Overflowing tabs no longer cover controls or intercept their
clicks. The physical macOS traffic-light inset is respected, and sidebar-visible
titles use the same control boundary. (#148)

## Verification and packages

Twenty chrome regressions cover X/Y/Shift wheel input, manual-scroll stability,
selection reveal, mixed Chinese/Arabic labels, 420/800/1280 point windows at
1x/1.5x/2x scaling, and real control clicks with twenty overflowing tabs. Existing
Command-number hints, tab drag reordering, window dragging and Windows caption
control tests passed. Full cross-platform CI, rendering and Release performance
gates passed before the fix merged.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and deb;
Windows x86-64 ZIP and MSI. Publication verifies package contents, update manifest
checksums and detached signatures.

The Unicode title and control-stream recovery fixes from v0.2.4 remain included.
