# mtty v0.2.7

[English](v0.2.7.md)

## 详情面板文件树支持右键菜单

详情面板的 Files 文件树此前只响应主键。现在在行上点击次键会打开该行的上下文
菜单：文件提供「用编辑器打开」「用默认程序打开」「在此切换目录」；目录提供
「在此新建终端」「在此切换目录」；两者都提供「在文件管理器中显示」「复制
路径」「复制相对路径」。菜单与 pane 上下文菜单一致（前台区域、钳制在窗口内、
Escape 或窗口内主键点击关闭），并复用已有的编辑器、外部打开、Tab 与输入
链路。（#156）

## macOS 开发包保留文件夹权限

`scripts/package-macos.sh` 之前用 ad-hoc 签名（`codesign --sign -`），每次构建
都会生成新的代码身份。macOS 把用户一次性授予的文件夹权限（文稿、桌面、下载）
绑定到那个身份上，因此 ad-hoc 构建始终无法被识别，重建后系统会再次询问。现在
打包会在本机存在可用身份时使用稳定身份签名——优先 `MTTY_CODESIGN_IDENTITY`，
否则取 `security find-identity` 中第一个 "Apple Development" 身份——没有时仍
回退到 ad-hoc。正式发布仍由 CI 用 Developer ID 重新签名。相关行为已写入
TROUBLESHOOTING，并更新了 README 与 INSTALL 的打包说明（中英文）。（#158）

## 验证与安装包

每项改动合并前完整跨平台 CI、渲染与性能门槛全部通过。
