# mtty v0.3.8

## A press on the merged row speaks the agent's own chords

When the agent's footer wire names the keystrokes per segment (miao 0.4.5
and newer), a press on the merged status row writes exactly those
keystrokes into the pane instead of synthesizing a mouse report at a
reported cell. The agent's terminal may have reclaimed the strip's row for
content entirely — the press still lands, on the same handlers a press
inside the terminal would reach. Agents that only report cells keep the
synthesized mouse press, unchanged.

## Maintenance and verification

Cross-platform CI covers Linux, macOS and Windows, along with rendering and
release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Existing macOS signing and notarization remain
in place.
