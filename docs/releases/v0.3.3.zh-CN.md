# mtty v0.3.3

[English](v0.3.3.md)

## 看得见的分组，聚在一起的标签

分组标签现在会说明自己属于哪一组。标题在名称前显示 `[分组]`，会话侧栏、
标签栏以及系统窗口标题都使用同一结构。此前分组几乎只有一条分隔线，单独
分到一组时看不出任何变化。（#235）

加入分组时，标签会移动到同组最后一个标签旁边，分隔线因此标记的是真正的
分组块，而不是把同组成员拆在两端。分组对话框会列出已有分组，加入只需点选，
不必重新输入完整名称——打错一个字会创建出第二个分组。

## 状态仍是图标，前缀已移除

agent 状态仍由标签图标表示：执行中是旋转圆弧，等待你时是带实心圆心的圆环，
完成时是实心圆。标题不再用文字重复它。（#237）

前缀原本只通过标题显示，而标题结构里没有它，因此“前缀…”菜单项、弹窗与
会话字段一并移除。旧版本保存的会话仍带有 `prefix`，恢复时会忽略该键。
（#239）

## 维护与验证

刷新定时 CI 生成的性能基线，既有绝对性能预算保持不变。跨平台 CI 覆盖
Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。发布流水线校验包内容、更新清单校验和与分离签名。
既有 macOS 签名与公证保持不变。
