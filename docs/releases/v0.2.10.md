# mtty v0.2.10

[简体中文](v0.2.10.zh-CN.md)

## Start miao in the current terminal

When miao is installed, a cat button appears at the top right of a ready
terminal. Clicking it types `miao` and Enter into that terminal, preserving the
working directory, shell environment and tab. The launcher hides while miao is
running and returns when the shell is ready again; it follows the active tab
or split. Read-only views and editor panes do not offer the launcher. (#173)

Installation detection also checks miao's standard installation directory, so
launching mtty from Finder does not depend on inheriting the shell's PATH.
Live terminal state controls visibility rather than saved agent reports or old
tab titles. A short startup guard prevents repeated clicks from sending the
command twice.

## Maintenance and verification

The scheduled CI performance baseline is refreshed. Absolute performance
budgets remain unchanged. (#171)

The launcher has replayed-input UI coverage and native screenshot verification.
Cross-platform CI covers Linux, macOS and Windows, along with rendering and
release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. The release pipeline checks package contents,
update-manifest checksums and detached signatures. Existing macOS signing and
notarization remain in place.
