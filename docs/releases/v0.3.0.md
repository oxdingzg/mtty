# mtty v0.3.0

[简体中文](v0.3.0.zh-CN.md)

## Keep work moving across panes and machines

The attention inbox brings waiting input, failures and completed work into one
place, with shortcuts back to the relevant pane, output and task. Command history
also exposes captured output for follow-up actions. (#177, #181)

Remote editing now checks for conflicting changes before saving and uses atomic
replacement where supported. SSH splits retain their remote context, and remote
paths and project information stay connected to their pane. Remote language
servers can be configured per host and project. (#179, #185, #194)

## Review and verify agent work

Task review combines committed, staged, unstaged and untracked changes. Review
marks are tied to the file revision, feedback can carry selected hunks, and
verification commands keep their results with the task. Repeated check output
has independent disclosure controls. (#184, #197)

Project Recipes turn repeatable project commands into discoverable actions.
Browser verification can run a configured browser command, capture a screenshot
and attach evidence to the task. (#188, #195)

ACP agent discovery and capability reporting make configured agents easier to
launch and inspect. Available actions follow the capabilities advertised by the
agent. (#189)

## Inspect artifacts without leaving the workspace

CSV and JSON previews provide structured views alongside the original file.
Editor navigation reveals distant columns after the actual viewport is known,
while nearby columns avoid unnecessary horizontal scrolling. (#192, #197)

## Terminal reliability

Pipe sessions publish a final wake after EOF so the UI can observe exit even
when no more output arrives. Windows hosted-shell verification waits for the
initial prompt before sending commands. (#199)

On Windows, documents larger than 256 KiB use background syntax parsing to keep
keystroke reparsing within the existing 16 ms frame budget. Highlighting remains
available up to the existing large-file limit. (#202)

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Update metadata includes checksums and detached
signatures.
