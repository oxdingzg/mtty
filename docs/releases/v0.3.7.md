## The agent's status merges into the status row

When the active pane runs an agent that reports a footer — miao 0.4.3 and
newer — the bottom status row carries the agent's own facts next to the
workspace path: the approval mode, the model, the provider · protocol tail
and the running build appear as press targets, and the agent names itself
and its build beside them. The window shows one status line instead of two.

A press on one of those targets is synthesized into the pane as a mouse
report at the recorded cell, so the agent's own click handler acts on it:
flipping auto-approve or opening the model picker works straight from
mtty's chrome, with the same behavior a press inside the terminal had. The
facts update live, and while the agent's leader menu waits, the row keeps
showing the chords.

Agents that never report a footer render the row exactly as before, and a
newer miao under an older mtty keeps painting its own strip, so neither
side forces the other to move first (#269).

## Maintenance and verification

Cross-platform CI covers Linux, macOS and Windows, along with rendering and
release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Existing macOS signing and notarization remain
in place.
