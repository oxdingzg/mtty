# mtty v0.2.4

[English](v0.2.4.md)

## Unicode 终端标题完整更新

中文和 emoji 标题不再因 UTF-8 连续字节与 C1 控制值重叠而被截断。标题更新支持
任意 PTY 数据包边界，包括拆分后的结束符。（#139）

OSC/DCS/APC 被 CAN、SUB 或新转义序列中断后，扫描器会正确恢复，独立处理下一个
标题。丢弃超长序列时也会清除 UTF-8 状态。host 的回放边界扫描区分独立 C1 ST 和
UTF-8 字节；VT parser 使用等价结束符，确保标题之后的屏幕文字正常显示。（#145）

保留 v0.2.3 的托管标题快照及重启恢复行为。

## macOS 按住 Command 显示 tab 数字

窗口获得焦点时，按住 Command，在 tab 图标位置显示 1–9，与 Command+1 至
Command+9 切换快捷键对应。松开 Command 或窗口失焦后恢复图标。顶部 tab 和
Session 侧边栏保留标题、宽度及点击区域；第十个及之后的 tab 继续显示图标。（#141）

## 回归覆盖与安装包

纯解析、图形测试改用字节 pipe，不再启动多余 shell 和 PTY，避免并行测试耗尽
macOS PTY。需要真实 shell 的测试和托管快照／重新挂接集成测试继续保留。（#143）

回归覆盖所有数据包大小、Unicode 标题、三种结束符、中断后的恢复、后续屏幕文字
以及 Command／焦点变化。完整工作区测试、Clippy、渲染和 Release 性能门槛验证
组合后的改动。发布流水线检查平台包内容、更新清单校验值及分离签名。

提供 macOS ARM64／Intel ZIP，Linux x86-64 tar.gz／AppImage／deb，以及
Windows x86-64 ZIP／MSI。
