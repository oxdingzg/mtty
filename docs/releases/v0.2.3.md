# mtty v0.2.3

[简体中文](v0.2.3.zh-CN.md)

## Restore terminal titles after updates and restarts

Hosted terminal snapshots now preserve OSC 0/2 program titles separately from the
screen grid. Reattaching to a running program restores the title immediately,
even when the program has not sent another title escape sequence since the
snapshot. This fixes miao tabs falling back to a folder or project label after an
application update or restart. (#135)

For older saved sessions, the active automatically named miao pane can recover
its recorded title from the saved tab display label. Manual tab names and
explicit newer snapshot values remain authoritative. Fresh titles sent by a
program still replace the restored title normally. (#135)

The fix cannot reconstruct a title that was already absent from the saved data.
For such a running miao Session, turn Terminal title off and back on in its
command palette to resend the current title.

## Verification and packages

Regression tests exercise a real hosted PTY across snapshot serialization and
reattachment, confirm fresh title updates, and check legacy snapshot migration.
Workspace tests, Clippy and Release performance gates validate the change.

The release provides macOS ARM64 and Intel bundles, Linux x86-64 archive,
AppImage and deb packages, and Windows x86-64 ZIP and MSI packages. The release
pipeline verifies package structure, the update manifest and configured detached
signatures before publication.
