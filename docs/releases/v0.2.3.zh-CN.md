# mtty v0.2.3

[English](v0.2.3.md)

## 更新和重启后恢复终端标题

托管终端快照现在会独立保存 OSC 0/2 程序标题。重新挂接仍在运行的程序时，即使程序
没有再次发送标题转义序列，也能立即恢复标题。修复 miao tab 在应用更新或重启后退回
目录名、项目别名的问题。（#135）

旧版保存的 Session 中，自动命名的活动 miao pane 可以从已记录的 tab 显示标题恢复。
手动 tab 名称和新格式中明确保存的值仍具有优先权；程序新发送的标题也会正常覆盖
恢复值。（#135）

如果标题在保存数据中已经丢失，修复无法凭空重建。对于仍在运行的 miao Session，
可在命令面板把 Terminal title 关闭再开启，让它重新发送当前标题。
