# mtty v0.2.5

[English](v0.2.5.md)

## Tab 横向滚动与右上角覆盖修复

Tab 较多或标题较长时，标签栏限制在独立的横向视口内。支持触控板左右滑动、普通
鼠标滚轮以及 Shift+滚轮。手动滚动后保留浏览位置，切换标签时自动显示选中项；
拖动标签继续用于调整顺序。（#148）

先布局右上角的面板、字号及窗口按钮，按它们的实际宽度预留空间。Tab 和标题的
绘制及点击范围限制在剩余区域，不再覆盖按钮或拦截按钮点击。保留 macOS 原生
窗口按钮的物理避让区域；显示侧栏时的标题也使用同样的控件边界。（#148）

## 验证与安装包

20 项 chrome 回归覆盖横向／纵向／Shift 滚轮、手动滚动稳定性、选中项可见性、
中文／阿拉伯文混合标题，以及 420／800／1280 点窗口在 1×／1.5×／2× 缩放下
的布局和 20 个溢出标签时的真实按钮点击。已有 Command 数字提示、标签拖动排序、
窗口拖动和 Windows 窗口控件测试通过。修复合并前完整跨平台 CI、渲染与 Release
性能门槛全部通过。

提供 macOS ARM64／Intel ZIP，Linux x86-64 tar.gz／AppImage／deb，以及
Windows x86-64 ZIP／MSI。正式发布检查包内容、更新清单校验值及分离签名。

包含 v0.2.4 已发布的 Unicode 标题及控制流恢复修复。
