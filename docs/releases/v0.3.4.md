# mtty v0.3.4

[简体中文](v0.3.4.zh-CN.md)

## The sidebar groups its sessions under the group name

The sidebar repeated each tab's `[group]` prefix on every row, which reads as
noise rather than structure. A named group now opens a section: its name heads
the rows that follow in the muted label style the host list already uses, those
rows indent under it, and they drop the prefix the heading replaces. The change
into the ungrouped tail keeps the tab bar's thin divider. The tab strip and the
OS window title keep the prefixed title, since a narrow strip still needs the
group inline. (ADR 0011, #245)

## The IME composition stays anchored

While an IME composition was open on Windows, the composition and candidate
windows visibly jumped around the screen instead of sitting at the terminal
cursor: egui-winit re-applies the IME cursor area on every frame that carries
input events, a live composition produces those frames continuously, and the
backend forwarded every call to IMM, re-anchoring the IME tens of times per
second against a terminal that redraws underneath (spinner, timer,
transcript). (#248)

The physical anchor is now deduplicated per window: IMM is reached only when
the area actually moved, and the cached anchor is forgotten when the IME
context is re-associated. The composition pins at the parked terminal cursor,
and the per-frame `ImmGetContext`/`ImmSet*` work is gone.

## Maintenance and verification

The scheduled CI performance baseline is refreshed; absolute performance
budgets are unchanged. Cross-platform CI covers Linux, macOS and Windows, along
with rendering and release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. The release pipeline checks package contents,
update-manifest checksums and detached signatures. Existing macOS signing and
notarization remain in place.
