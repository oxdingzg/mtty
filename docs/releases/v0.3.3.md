# mtty v0.3.3

[简体中文](v0.3.3.zh-CN.md)

## Groups you can see, and tabs that stay together

A grouped tab now says which group it belongs to. The title leads with
`[group]` before the pane's name, both in the session sidebar and in the tab
strip, and the OS window title uses the same structure. Grouping was previously
little more than a divider, so a tab alone in its group looked unchanged. (#235)

Joining a group also moves the tab next to the last tab already carrying that
name, so the divider marks a real block instead of splitting members across the
strip. The Group dialog lists the groups already in use, so joining one is a
click rather than retyping an exact name — a typo used to create a second group.

## The state stays an icon, and the prefix is gone

An agent's state remains the tab icon: a rotating arc while working, a ring with
a solid core while waiting, and a filled disc when a turn finishes. The title
does not repeat it as text. (#237)

The tab prefix was only ever visible in the title and is not part of the title
structure, so the Prefix menu entry, its dialog and its session field are
removed. A session saved by an older build still carries `prefix`; restoring it
ignores the key. (#239)

## Maintenance and verification

The scheduled CI performance baseline is refreshed; absolute performance
budgets are unchanged. Cross-platform CI covers Linux, macOS and Windows, along
with rendering and release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. The release pipeline checks package contents,
update-manifest checksums and detached signatures. Existing macOS signing and
notarization remain in place.
