# mtty v0.3.2

[简体中文](v0.3.2.zh-CN.md)

## Keep restored history separate from a fresh shell

When a saved pane starts a new shell, its previous contents now return as
scrollback history, with a clean live screen and the cursor at the origin.
This avoids mixing old full-screen application fragments with the absolute
cursor positioning used by a fresh Windows ConPTY during startup or resize.
Scroll up to view the previous session's contents. Reattaching to a surviving
PTY host continues to restore its exact live screen. (#217)

Inline images restored with the text keep their row anchors as the contents
move into history, including when the scrollback limit is reached.

## Verification

Regression coverage includes fresh-screen repaints, alternate-screen round
trips, restored image anchors and real Windows ConPTY startup and resize.
Linux, macOS and Windows CI, rendering and performance checks cover the fix.
The complete intermittent sequence reported in #216 has not yet been
reproduced in a local GUI session.

Packages include macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz,
AppImage and deb; and Windows x86-64 ZIP and MSI.
