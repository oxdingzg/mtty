# mtty v0.3.2

[English](v0.3.2.md)

## 分开恢复历史与新 shell 的活动屏幕

保存的窗格需要启动新 shell 时，旧内容现在会恢复到回滚历史中，活动屏幕
保持干净，光标从原点开始。这可以避免 Windows ConPTY 在启动或调整窗口
大小时使用绝对光标位置重绘，将旧的全屏程序片段与新 shell 输出混在一起。
向上滚动即可查看上次会话的内容。重新连接仍在运行的 PTY host 时，仍按
精确快照恢复其活动屏幕。（#217）

随文本恢复的内联图片也会同步移动行锚点，包括达到回滚历史上限时的情况。

## 验证

回归测试覆盖新屏幕重绘、备用屏幕切换、图片恢复锚点，以及真实 Windows
ConPTY 的启动和窗口大小调整。修复经过 Linux、macOS、Windows CI、渲染
及性能检查。#216 报告的完整偶发触发过程尚未在本机 GUI 会话中复现。

安装包包括 macOS ARM64 和 Intel ZIP，Linux x86-64 tar.gz、AppImage、deb，
以及 Windows x86-64 ZIP 和 MSI。
