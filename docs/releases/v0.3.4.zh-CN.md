# mtty v0.3.4

[English](v0.3.4.md)

## 侧栏会话按分组名归组

此前侧栏在每一行都重复标签的 `[分组]` 前缀，读起来是噪音而不是结构。命名
分组现在会展开成一个段落：组名沿用主机列表的弱化标签样式，作为其后各行
的标题；成员行在标题下缩进，并去掉被标题取代的前缀。进入未分组尾部时仍
保留标签栏原有的细分隔线。标签条与系统窗口标题保留带前缀的标题——窄的
标签条仍需要组名内联显示。（ADR 0011，#245）

## IME 组合窗口不再乱跳

在 Windows 上，输入法组合与候选窗口不再稳稳停在终端光标处，而是明显地
来回跳动：egui-winit 会在每个带输入事件的帧上重新设置 IME 光标区域，组合
进行中这些帧连续不断地到达，而后端把每次调用都转发给 IMM，等于每秒把
输入法重新锚定几十次——叠加上层不断重绘的终端（spinner、计时器、滚动
输出）就是屏幕上的乱跳。（#248）

现在每个窗口对物理锚点做去重：只有区域真的移动时才访问 IMM，IME 上下文
重新关联时丢弃缓存的锚点。组合窗口稳稳停在终端光标处，每帧的
`ImmGetContext`/`ImmSet*` 调用也随之消失。

## 维护与验证

刷新定时 CI 生成的性能基线，既有绝对性能预算保持不变。跨平台 CI 覆盖
Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。发布流水线校验包内容、更新清单校验和与分离签名。
既有 macOS 签名与公证保持不变。
