# mtty v0.3.6

[简体中文](v0.3.6.zh-CN.md)

## A multi-line paste stays one paste on Windows

Pasting several lines into a pane on Windows submitted them line by line
instead of inserting the text as one draft. ConPTY turns a bracketed paste
into key presses: it drops the `ESC[200~ ESC[201~` markers and delivers every
line break as Enter, even when the application has already enabled bracketed
paste with `?2004h`.

For a multi-line paste into a pane whose application enabled bracketed paste,
mtty now sends the legacy Ctrl+V byte and lets that application read the
clipboard itself. miao answers Ctrl+V by reading the clipboard and keeps the
text as one draft, so a pasted prompt is no longer submitted while it is still
arriving. Single-line pastes, and panes without bracketed paste, keep the text
bytes so shells and editors behave as before.

## Maintenance and verification

Cross-platform CI covers Linux, macOS and Windows, along with rendering and
release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Existing macOS signing and notarization remain
in place.
