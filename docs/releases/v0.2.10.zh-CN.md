## 在当前终端启动 miao

安装 miao 后，就绪终端的右上角会显示猫形按钮。点击等同于在当前终端输入
`miao` 并回车，保留当前工作目录、shell 环境和标签页。运行 miao 时按钮隐藏，
回到 shell 后恢复，并随当前标签页或分屏切换。只读视图和编辑器窗格不显示启动按钮。
（#173）

安装检测也覆盖 miao 的标准安装目录，因此从 Finder 启动 mtty 时无需依赖继承
shell 的 PATH。按钮显隐依据终端实时状态，不受历史 agent 记录或旧标签标题影响；
启动阶段短暂防重复点击，避免重复发送命令。

## 维护与验证

刷新定时 CI 生成的性能基线，既有绝对性能预算保持不变。（#171）

启动按钮具有真实输入回放的 UI 回归覆盖和原生截图验证。跨平台 CI 覆盖 Linux、
macOS、Windows，以及渲染检查和 release 模式性能门。

发行包包括：macOS ARM64、Intel ZIP；Linux x86-64 tar.gz、AppImage、deb；
Windows x86-64 ZIP、MSI。发布流水线检查包内文件、更新清单校验和及分离签名；
沿用已有 macOS 签名与公证流程。
