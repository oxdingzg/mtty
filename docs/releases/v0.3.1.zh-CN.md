# mtty v0.3.1

[English](v0.3.1.md)

## 从标题栏登录 Hub 账号

安装 miao 后，窗口控制按钮旁会显示账号入口：未绑定账号时显示 `Sign In`，
当前窗格的 miao Runtime 报告已连接 Hub 账号后显示 `Account`。点击打开一个小窗口，
填写 Hub 地址、邮箱、密码和可选的机器名称。（#212）

登录经 miao 的 private-pipe bridge 发往当前窗格所属的 Runtime，账号凭据与 Hub
绑定仍由 miao 持有；mtty 只显示实时状态并转发请求。attached、缺失或格式错误的
窗格上下文会在任何凭据发出之前被拒绝，关闭窗口会取消进行中的请求。终端用户可用
`miao remote login/status/logout` 完成同样的登录，该命令随下个 miao 版本发布。

## 可选，而非必需

登录保持可选：未安装 miao 时不显示入口，没有账号也能继续使用远程控制，
mtty 仍然从不自行调用模型。PRODUCT.md 与 README 中的非目标表述已从“无账号”
收窄为“无强制登录”。

## 维护与验证

刷新定时 CI 生成的性能基线，既有绝对性能预算保持不变。跨平台 CI 覆盖 Linux、
macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。发布流水线校验包内容、更新清单校验和与分离签名。
既有 macOS 签名与公证保持不变。
