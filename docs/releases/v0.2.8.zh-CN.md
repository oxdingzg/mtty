# mtty v0.2.8

[English](v0.2.8.md)

## macOS 正式包已签名并公证

此前 macOS 安装包是 ad-hoc 签名，在没有批准过旧版本的新机器上会被 Gatekeeper
拦截：必须先在「隐私与安全性」里点「仍要打开」才能启动。现在正式发布改为使用
Developer ID 身份签名（启用 hardened runtime），发布前通过 App Store Connect
API 完成公证，票据随 ZIP 一起分发。新下载的安装包可以像普通应用一样直接打开，
不再需要绕道安全设置。（#162）

CI 发布流水线会把签名证书导入 job 本地钥匙串，并用 `--wait` 提交每个 macOS
安装包做公证；公证被拒时发布直接失败，不会发出未签名的构建。

## 性能基线刷新

CI 性能基线从最近一次定时运行的结果刷新，比较门槛改为以当前硬件数据为准，
而不是旧机器的数字。（#154）

## 验证与安装包

每项改动合并前完整跨平台 CI、渲染与性能门槛全部通过。

提供 macOS ARM64／Intel ZIP，Linux x86-64 tar.gz／AppImage／deb，以及
Windows x86-64 ZIP／MSI。正式发布检查包内容、更新清单校验值及分离签名。

包含 v0.2.7 已发布的右键菜单与开发包签名修复及更早的修复。
