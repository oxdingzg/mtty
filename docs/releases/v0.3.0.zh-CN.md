# mtty v0.3.0

[English](v0.3.0.md)

## 串联窗格与远程工作

待处理事项收件箱集中展示等待输入、执行失败和完成待审阅状态，并可跳回对应
窗格、提取输出或进入任务。命令历史也支持对捕获的输出执行后续操作。
（#177、#181）

远程编辑保存前检查冲突，在支持的环境中使用原子替换。SSH 分屏保留远程上下文，
远程路径和项目信息跟随窗格。远程语言服务器可按主机和项目配置。
（#179、#185、#194）

## 审阅并验证 Agent 工作

任务审阅汇总已提交、已暂存、未暂存和未跟踪的变更。审阅标记绑定文件版本，
反馈可携带选中的 diff hunk，验证命令的结果保存在任务中。重复的检查结果拥有
独立的输出展开控件。（#184、#197）

项目 Recipes 将可重复执行的项目命令变成可发现的操作。浏览器验证可调用配置的
浏览器命令、捕获截图，并将证据附加到任务。（#188、#195）

ACP Agent 发现与能力展示让配置的 Agent 更容易启动和检查；可用操作以 Agent
声明的协议能力为依据。（#189）

## 在工作区内检查产物

CSV 和 JSON 预览在原始文件之外提供结构化视图。编辑器在真实视口确定后再定位
远处的列，跳到附近列时避免不必要的水平滚动。（#192、#197）

## 终端可靠性

管道会话在 EOF 后发布最终唤醒，即使没有更多输出，界面也能观察到会话退出。
Windows 托管 Shell 验证会先等待初始提示符再发送命令。（#199）

安装包包括 macOS ARM64 与 Intel ZIP、Linux x86-64 tar.gz / AppImage / deb，
以及 Windows x86-64 ZIP / MSI。更新元数据包含校验和与独立签名。
