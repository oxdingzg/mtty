## Windows 上纯图片粘贴能到达面板

在 Windows 面板里复制一张截图再按 Ctrl+V 没有任何反应。mtty 其实已经读取
剪贴板图片并写入 `MTTY_CLIPBOARD_FILE`，随后用一个空的 bracketed paste
作为“粘贴发生了”的信号；但 ConPTY 会在应用看到之前丢掉这对空的
`ESC[200~ ESC[201~`，于是面板一个字节都收不到，图片被静默忽略。

现在 Windows 上对“只有图片”的粘贴改发传统的 Ctrl+V 字节（`0x16`）。应用
本来就把 Ctrl+V 当作“自己读剪贴板”，而 miao 的读取优先使用宿主写好的文件，
图片因此会作为附件进入输入框。文本粘贴保持不变，Unix 终端继续使用它们已经
支持的空 bracketed paste。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。既有 macOS 签名与公证保持不变。
