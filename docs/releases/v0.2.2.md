# mtty v0.2.2

[简体中文](v0.2.2.zh-CN.md)

## Clearer agent task states

Agent tabs and the task sidebar now distinguish paused unfinished work, background
waits and unavailable observations with separate badges: amber pause bars, an
accent clock and a muted question mark. Explicit completion retains its green
full circle. Localized hover text explains each state, making it easier to tell
whether an agent is working, waiting or needs attention. (#131)

The companion task-outcome retention fix is
[miao #609](https://github.com/oxdingzg/miao/pull/609). Use a miao build containing
that fix to retain its completed or paused task outcome during later background
activity.

## Release reliability

- Check CLI sources, patched dependencies and build configuration in the relevant
  compilation and platform-test jobs. (#125)
- Require successful main-branch CI for the exact release commit, verify the tag
  matches the workspace version, and rehearse packaging-related changes before
  publication. (#127)
- Synchronize and warm up hosted-output performance measurements, use repeated
  sample medians, and retain raw measurements for diagnosis. The performance
  budget is unchanged. (#129)

## Packages

The release pipeline builds and validates macOS ARM64 and Intel bundles, Linux
x86-64 archive/AppImage/deb packages, and Windows x86-64 ZIP/MSI packages.
Update manifests and configured detached signatures are verified before
publication.
