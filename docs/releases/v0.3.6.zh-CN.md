## Windows 上多行粘贴保持为一次粘贴

在 Windows 面板里粘贴多行文本时，内容会被逐行提交，而不是作为一份草稿
插入。ConPTY 会把 bracketed paste 拆成按键：丢掉 `ESC[200~ ESC[201~`
标记，并把每个换行都变成回车——即使应用已经用 `?2004h` 启用了 bracketed
paste 也一样。

现在，当多行文本粘贴到已启用 bracketed paste 的面板时，mtty 会改发传统的
Ctrl+V 字节，由应用自己读取剪贴板。miao 收到 Ctrl+V 后会读剪贴板并把文本
作为一份草稿保留，因此粘贴的提示词不会在还没输完时就被提交。单行粘贴以及
未启用 bracketed paste 的面板仍发送原始文本，shell 与编辑器的行为不变。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。既有 macOS 签名与公证保持不变。
