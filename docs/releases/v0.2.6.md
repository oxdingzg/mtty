# mtty v0.2.6

[简体中文](v0.2.6.zh-CN.md)

## No more unbounded memory growth in one-column panes

Shrinking a pane to a single column no longer exhausts the machine's memory.
Alacritty's grid needs two columns to hold a double-width cell, so reflowing a
line containing CJK or emoji characters into one column never consumed those
cells and kept allocating new rows (alacritty/alacritty#7697). Engine
construction and resize, local, SSH and PTY-host spawn sizes and window layout
now clamp widths to a two-column minimum, and terminal size queries report the
clamped size so programs always see a consistent grid. (#151)

## Verification and packages

Engine-level and terminal-level regressions drive a Chinese + emoji screen
through one hundred narrow/wide resize cycles and require the screen to
round-trip identically, check the construction and resize size invariants, and
confirm the CSI 18 t report agrees with the clamped grid. Full cross-platform
CI, rendering and performance gates passed before the fix merged.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Publication verifies package contents, update
manifest checksums and detached signatures.

The scrollable tab strip and titlebar control fixes from v0.2.5 remain
included.
