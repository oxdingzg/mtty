# mtty v0.2.9

[简体中文](v0.2.9.zh-CN.md)

## A crash while typing with a CJK input method fixed

mtty aborted on the main thread while typing with a Chinese input method: the
IME patch inside the vendored winit read `NSApp.currentEvent.characters` to
tell IME commits from ordinary keys, and on macOS 26 the new NSInputAnalytics
path can deliver `insertText:` while the current event is not a keyboard
event. `-[NSEvent characters]` then trips an AppKit assertion and the app
dies with SIGABRT — two crash reports were collected (2026-10-14 and
2026-10-15). The characters are now read only for real key-down events; any
other event compares as not-differing, exactly like the no-current-event
case. (#168)

## Verification and packages

Full cross-platform CI, rendering and performance gates passed before each
change merged.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Publication verifies package contents, update

included.
