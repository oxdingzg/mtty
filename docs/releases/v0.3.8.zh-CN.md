# mtty v0.3.8

[English](v0.3.8.md)

## 合并行上的点击，说出代理自己的和弦

当代理的 footer wire 为每个段点名了按键（miao 0.4.5 及以上），合并状态行上的点击会把那些按键原样写进面板，而不是按上报的单元格合成鼠标事件。代理的终端可能已把状态行彻底还给对话内容——点击依然落点正确，与终端内点击触达的处理逻辑完全一致。只上报单元格的代理仍走原来的合成鼠标事件，行为不变。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。既有 macOS 签名与公证保持不变。
