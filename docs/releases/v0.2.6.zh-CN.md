# mtty v0.2.6

[English](v0.2.6.md)

## 修复 pane 缩到 1 列时的无限内存增长

把 pane 缩到单列宽度不再耗尽整机内存。Alacritty 的网格需要两列才能容纳一个
宽字符（中文、emoji 等）单元，把含中文或 emoji 的行重排进单列时这些单元永远
无法被消费，引擎会不断分配新行（alacritty/alacritty#7697）。现在引擎创建与
resize、本地／SSH／PTY host 的启动尺寸以及窗口布局都会把宽度钳制到最少两列，
终端尺寸查询也返回钳制后的尺寸，程序看到的网格始终一致。（#151）

## 验证与安装包

引擎级与终端级回归让含中文和 emoji 的屏幕经过一百次「缩窄／放宽」循环后保持
内容完全一致，并覆盖创建与 resize 的尺寸约束、CSI 18 t 尺寸应答与钳制后网格
的一致性。修复合并前完整跨平台 CI、渲染与性能门槛全部通过。

提供 macOS ARM64／Intel ZIP，Linux x86-64 tar.gz／AppImage／deb，以及
Windows x86-64 ZIP／MSI。正式发布检查包内容、更新清单校验值及分离签名。

包含 v0.2.5 已发布的 Tab 横向滚动与右上角控件修复。
