# mtty v0.2.6

[English](v0.2.6.md)

## 崩溃修复：单列面板中的无界重排

终端面板被短暂压缩到仅一列时，可能耗尽内存并中止整个进程。网格引擎
（alacritty 0.25）重排双宽字符至少需要两列；在只有一列时，宽字符会在每次循环中
被重新放回剩余内容里，行数无界增长，而回滚上限只在循环结束后才生效。持有宽字符
文本（中文、emoji）的面板随后被调整为一列时——例如调整窗口大小，或分屏短暂折叠
——会卡住 UI 线程（停止出帧），同时私有内存一路攀升到数 GB，最终因分配失败而
abort。

现在终端网格在构造、resize、PTY 尺寸以及面板布局处都至少保留两列，且 shell 看到
的 PTY 尺寸与屏幕保持一致。（#150、#151）

## 验证与安装包

中文与 emoji 内容在窄／宽尺寸间往返重排后内容保持不变，并覆盖零尺寸构造和
查询／PTY 尺寸一致性。修复合并前完整跨平台 CI（含 Windows 测试任务、渲染与
Release 性能门槛）全部通过。

提供 macOS ARM64／Intel ZIP，Linux x86-64 tar.gz／AppImage／deb，以及
Windows x86-64 ZIP／MSI。正式发布检查包内容、更新清单校验值及分离签名。

包含 v0.2.5 已发布的 Tab 横向滚动及标题栏覆盖修复。
