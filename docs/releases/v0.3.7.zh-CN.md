# mtty v0.3.7

[English](v0.3.7.md)

## 代理的状态并入状态行

当活动面板运行的是会上报状态栏信息的代理（miao 0.4.3 及以上）时，底部
状态行会在工作区路径旁展示代理自己的信息：审批模式、模型、提供商 · 协议
尾段与运行版本会作为可点击目标出现，代理用它自报名称和版本。窗口从此只
有一行状态，而不是两行。

点击这些目标时，mtty 会按记录的单元格向面板合成一次鼠标事件，由代理自己
的点击处理逻辑响应：切换 auto-approve、打开模型选择器都可以直接在 mtty
的界面边框上完成，行为与在终端内点击完全一致。信息实时更新；代理的
leader 菜单等待期间，这一行仍显示按键和弦。

从不上报状态栏信息的代理，状态行渲染与之前完全一致；老版本 mtty 里的新
版 miao 也会继续自己绘制状态条，两边谁都不强迫谁先动（#269）。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。既有 macOS 签名与公证保持不变。
