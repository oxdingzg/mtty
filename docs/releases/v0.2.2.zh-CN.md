# mtty v0.2.2

[English](v0.2.2.md)

## 更清晰的 Agent 任务状态

Agent tab 和任务侧栏现在使用不同标记区分未完成暂停、后台等待和无法观测的状态：
黄色暂停条、强调色时钟和弱化问号。明确完成仍使用绿色实心圆。本地化悬浮说明解释
各状态，方便判断 Agent 正在工作、等待后台任务，还是需要关注。（#131）

配套的任务结果保留修复是 [miao #609](https://github.com/oxdingzg/miao/pull/609)。
使用包含该修复的 miao 构建，可以在后续后台活动期间保留已完成或未完成暂停的任务结果。

## 发布可靠性

- 将 CLI 源码、补丁依赖和构建配置纳入相应的编译及平台测试，补齐路径漏检。（#125）
- 发布必须通过同一提交的主分支 CI，tag 必须匹配 workspace 版本；包装相关变更
  在发布前自动进行演练。（#127）
- 吞吐性能测试增加就绪同步和预热，采用多轮采样中位数，保存原始测量数据。
  原有性能门槛保持不变。（#129）

## 安装包

发布流水线构建并验证 macOS ARM64 和 Intel 安装包、Linux x86-64 压缩包／AppImage／deb，
以及 Windows x86-64 ZIP／MSI。发布前验证更新清单和已配置的分离签名。
