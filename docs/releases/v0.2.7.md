# mtty v0.2.7

## A context menu in the details file tree

The details panel's Files tree only reacted to the primary button. A secondary
click on a row now opens a context menu with that row's file actions: a file
offers Open (editor), Open with Default App and Change Directory Here; a
directory offers New Terminal Here and Change Directory Here; both offer Reveal
in File Manager, Copy Path and Copy Relative Path. The menu is drawn like the
pane context menu — foreground area, clamped to the window, closed by Escape or
an outside primary press — and reuses the existing editor, external-open, tab
and input paths. (#156)

## A macOS dev bundle that keeps its folder permissions

`scripts/package-macos.sh` signed the bundle ad-hoc (`codesign --sign -`), which
mints a new code identity on every build. macOS keys the folder permission the
user grants once (Documents, Desktop, Downloads) to that identity, so an ad-hoc
build was never recognised again and the prompt returned after every rebuild.
Packaging now signs with a stable identity when the machine has one —
`MTTY_CODESIGN_IDENTITY`, else the first "Apple Development" identity from
`security find-identity` — and falls back to ad-hoc as before. Release builds
keep re-signing with the Developer ID in CI. The behaviour is documented in
TROUBLESHOOTING and the packaging notes in README and INSTALL (en/zh). (#158)

## Verification and packages

Full cross-platform CI, rendering and performance gates passed before each
change merged.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Publication verifies package contents, update
manifest checksums and detached signatures.

The v0.2.6 single-column reflow fix and earlier fixes remain included.
